# TABI-TABI

Offline Android cinematic folklore mystery-adventure set in Barrio Lawom.

## Development

Godot 4 / GDScript, landscape 3D isometric adventure. Quality-first vertical slice: **Night 1 — The Light on the River (Santelmo)**.

Project is under active development. The game is **not yet playable** and no APK has been validated.

### Canon

Based on *TABI-TABI Final Master Story Script & Development Plan*, design-lock edition v1.0, 14 November 2026. The seven-night narrative is planned; development will only expand past Night 1 after Android gameplay validation.

### Branch workflow

`main` stays the baseline. Features are developed and reviewed on dedicated branches; successful automated checks alone do not qualify a chapter as playable.
