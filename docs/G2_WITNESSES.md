# G2.3 — Night 1 resident dialogue and evidence revisions

- Lola responds to completed evidence, encouraging observation rather than premature fear.
- Dado distinguishes an eyewitness observation from an explanation. Revisiting him does not manufacture another clue.
- Mara's ledger testimony is contextualized by the old mooring location; the player can revisit witnesses in different orders.
- Sabel requests privacy for the boatman's family and the prototype records the player's respect without publishing personal details in the notebook.
- Witness interactions save offline immediately so evidence isn't silently lost when the app closes.
- The NPC dialogue is deterministic, stored separately from the scene controller and covered by regression tests.

This is an authored dialogue pass, not a branching full conversation UI or finished voice/cinematic pass. The physical NPCs still use temporary world markers; consent currently has one respectful default rather than a full explicit choice interface.
