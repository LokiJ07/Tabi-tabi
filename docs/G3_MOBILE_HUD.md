# G3 — Mobile HUD and notebook legibility pass

Based on an actual user Android screenshot, this pass prioritizes readable story text and eliminates a misleading notebook interaction.

- The notebook is a dedicated centered overlay, separate from dialogue, with visible CLOSE, GUIDE GENTLY and CHASE AWAY controls.
- Opening the notebook **no longer changes private theory**. Only deliberate theory button presses change it, and the decision is saved offline.
- Dialogue is anchored higher on screen, away from the D-pad and lower choice row.
- Title reflects Barrio Lawom, and objective/stage labels are slightly larger.
- The four-direction move controls and Focus/Interact layout are unchanged because user feedback says they are functional.

Still pending real-device validation: safe area handling, long dialogue pagination, control remapping, polished UI art and legibility across small screens.
