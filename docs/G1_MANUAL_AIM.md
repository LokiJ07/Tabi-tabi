# G1.2 — Manual right-thumb lantern aim

- Removed the Santelmo auto-target lock from Focus.
- Added independent draggable right-thumb directional aim pad for the lantern.
- Walking still uses left-hand controls; lantern heading remains independent while dragging.
- The hold FOCUS button keeps the heading steady; the pad allows a free direction.
- Mouse drag is supported for desktop testing.

This is only an input prototype; actual Android thumb feel, accessibility options and final touch geometry remain unverified.
